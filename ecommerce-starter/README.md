# LoveGrownJewelry — Ecommerce Starter

This folder contains a minimal Next.js starter scaffold to migrate the current static marketing site into a production-ready ecommerce storefront.

Planned work

1. Replace the static landing page with a Next.js storefront.
2. Integrate a product CMS (Shopify / headless CMS / Sanity) or use a JSON product catalog for MVP.
3. Implement cart + checkout using Stripe or Shopify Storefront API.
4. Add order management and webhook handlers for fulfillment.
5. Add analytics, SEO, and performance optimizations.

How to run locally

1. cd ecommerce-starter
2. npm install
3. npm run dev

Notes

- This scaffold is intentionally minimal. It is a starting point; next steps include wiring payments, product import, and shipping configuration.
